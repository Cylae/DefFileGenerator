02 · Architecture

A small core with explicit boundaries.

EXTRACTOR

Document ingestion

pdfplumber · openpyxl · csv.Sniffer · defusedxml. Lazy iterators keep the pipeline composable and reduce unnecessary materialization.

MAPPER

Column inference & cleanup

Samples source rows, resolves vendor header synonyms, applies address offsets and converts manufacturer-specific type notation.

GENERATOR

Webdyn semantic model

Computes Info fields, tags, coefficients, register widths, action codes and output rows.

VALIDATOR

Integrity gates

Checks Modbus bounds, type validity, tag uniqueness and interval / bit-slice overlap before deployment.

Register integrity04
04 · Security

Defensive by construction.

CSV injection

Formula-triggering values and Unicode variants are escaped before spreadsheet consumption.

XXE protection

Untrusted XML is parsed through defusedxml; DTD and external entity attacks are rejected.

Atomic output

Definitions are staged, fsynced and atomically replaced so a failed write cannot truncate the existing production file.

Bounded uploads

The web API streams request bodies in chunks and enforces a 10 MiB upload ceiling.

Error privacy

Internal exception details stay in server logs instead of leaking filesystem paths or parser internals to clients.

Automation trust

Privileged auto-merge only accepts owner-authored, same-repository PRs after successful CI.

The web CORS policy remains public for non-credentialed access. Credentials are explicitly disabled while wildcard origins are in use.

06 · Quick start

From documentation to definition in one command.

Install the project, run a conversion, then validate the generated definition before deployment.

# install core + web interface python -m pip install -e ".[web]" # full conversion deffilegen run datasheet.pdf \ --manufacturer "Huawei" \ --model "SUN2000" \ -o huawei_sun2000.csv # strict validation deffilegen validate huawei_sun2000.csv # web UI / REST API uvicorn web.app:app --host 127.0.0.1 --port 8000

Extract only

deffilegen extract register-map.xlsx --sheet Registers -o normalized.csv

Generate only

deffilegen generate normalized.csv --manufacturer SMA --model STP5000 -o sma.csv
